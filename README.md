# 🤖 Code-GPT

Code-GPT is an AI-powered coding assistant built with **Django**, **FastAPI**, **Groq API**, and **MongoDB**. It helps users generate, explain, debug, and improve code through an interactive chat interface.

## 🚀 Features

- AI-powered code assistance
- User authentication
- Chat history
- Copy code functionality
- Responsive UI
- Image preview support

## 🛠️ Tech Stack

- Python
- Django
- FastAPI
- MongoDB
- PostgreSQL
- HTML, CSS, JavaScript
- Groq API

## ⚙️ Installation

```bash
git clone https://github.com/Rachit-2007/Code-GPT.git
cd Code-GPT
pip install -r requirements.txt
python manage.py runserver
```
